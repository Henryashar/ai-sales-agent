# Local launch

## Start the app

1. Double-click `start.bat` in `C:\AIProjects\ai-sales-agent`
2. Wait a few seconds for the browser to open at [http://localhost:3000](http://localhost:3000)
3. Sign in with any name/email and this access code:

```
local-only
```

This is a local-only shared code (not a security control). Use it so the sign-in screen does not block you.

## Stop the app

Press `Ctrl+C` in the terminal window that `start.bat` opened.

## Optional desktop shortcut

1. Right-click `start.bat` → **Show more options** → **Create shortcut**
2. Drag the shortcut to your Desktop
3. (Optional) Rename it to **AI Sales Agent**
